# Melissa Cubillas Website

A modern, editorial website for Melissa Cubillas, psychic medium and spiritual teacher.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Updating content

The homepage content is in `app/page.tsx`. Colors and layout are in `app/globals.css`.

## Publishing

This project is ready for GitHub and Vercel. Import the GitHub repository in Vercel; every future push to `main` will publish automatically.
