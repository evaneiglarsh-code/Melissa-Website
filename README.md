# Melissa Cubillas Website

A modern, editorial website for Melissa Cubillas, psychic medium and spiritual teacher.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Updating content

The homepage content is in `app/page.tsx`. Colors and layout are in `app/globals.css`.

## Publishing

This repository is connected to Vercel. Every update to `main` automatically builds and publishes a new version.
